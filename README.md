# Bahan Mobile Odoo

Repositori bahan/material pendukung untuk proyek aplikasi mobile absensi
berbasis Odoo. Repositori ini hanya menyimpan arsip paket proyek sebagai
bahan pengembangan dan referensi — bukan tempat pengembangan kode aktif.

## Isi

- `mobile_absensi 15-10-2026.zip` — arsip paket aplikasi mobile absensi
  (snapshot 15 Oktober 2026).

## Catatan

- Arsip lama `mobile_absensi.zip` pernah dibersihkan dari root repositori
  (lihat PR #1). Berkas biner berukuran besar sebaiknya dibagikan lewat
  GitHub Releases, bukan disimpan di riwayat git, agar clone tetap ringan.
- Pengembangan aplikasi mobile-nya sendiri dilakukan di repositori
  aplikasi tersendiri.
